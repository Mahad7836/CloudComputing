Infrastructure as Code (IaC)

Infrastructure as Code means managing infrastructure using code instead of manual setup.

Terraform

Terraform is used to:

Provision resources

Define infrastructure using templates

Clone environments

Update environments

How Terraform Works

Templates describe your environment

Uses underlying APIs of each service

Deploys resources automatically

Human-readable and machine-consumable

Can be stored and version controlled (e.g., GitHub)

Common Use Cases

Update commands to modify environment

Write new commands to clone environment

Maintain consistent infrastructure
