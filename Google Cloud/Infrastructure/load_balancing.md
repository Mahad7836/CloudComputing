# Load Balancing

Load balancing distributes user traffic across multiple instances of an application.

## Benefits:
Reduces risk
Increases availability
Improves performance
Fully distributed software-defined service
Supports cross-region load balancing

## Types of Load Balancers
### Application Load Balancer (ALB)

Works at Layer 7 (OSI model)
Supports:
SSL/TLS termination
Content-based routing
Used for HTTP/HTTPS traffic
Network Load Balancer (NLB)
Works at Layer 4 (OSI model)
Handles:

TCP
UDP traffic
Low latency
High throughput
HTTPS Load Balancing

### Used when:

Cross-regional load balancing is required
Balancing web applications
PoP (Point of Presence)

PoP = Location where Google’s network connects to the rest of the internet.
