# Multiple VPCs

Used for robust networking solutions.
Organizations may use multiple VPCs for:
Environment separation (Dev, Test, Prod)
Security isolation
Scalability

VPC Communication
VPC Peering

Allows VPCs to communicate privately
Uses firewall and traffic rules
Decentralized approach

Shared VPC

Alternate approach.
Allows an organization to connect resources from multiple projects to a common network
One host project
Other projects attach to the host

Useful for centralized network management.
