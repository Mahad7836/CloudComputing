# Hybrid Cloud Connectivity

## Google Cloud can connect to other networks (like on-premises).

### IPsec VPN
Creates encrypted tunnel connection
Uses cloud Router for dynamic routing
Secure connection over public internet

### Carrier Peering
Provides access to Google services (like Google Workspace)
Connects through telecom provider
Router may be placed in same data center as VPC connection point

### Dedicated Interconnect
Direct connection to Google
High uptime
High performance
Suitable for enterprise workloads

### Partner Interconnect
Connects on-premises network to VPC
Uses Google partner provider
